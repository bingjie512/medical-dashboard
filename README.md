# 血氧与心电模块上位机测试工具 (进阶版)

这是为综合实验开发的上位机网页应用，包含了血氧（SpO2）与心电（ECG）数据的完全解析和波形呈现功能。
本应用由 **三杯橘** 研发。

## 特性
- 支持基于浏览器的完全静态托管（可部署于 GitHub Pages）。
- 个性化定制：暗黑玻璃拟态主题、深橘色与青色点缀，专属研发人员标识。
- 分层架构：UI与解析逻辑高度分离，包含核心解析器（基于状态机和滑动窗口）、文件数据流适配器和独立的数据绑定层。
- 进阶版支持：支持加载预设的 `SPO2_20220602095410.bin` 和 `ECG_20250421093851.bin` 回放，支持心电导联报警监测。
- 完备的播放控制（支持暂停、播放、自定义进度拖动、0.5x~4x倍速）。

## 如何运行

1. 确保安装了 Node.js (推荐 v18+)。
2. 在该项目目录下运行：
   ```bash
   npm install
   npm run dev
   ```
3. 打开浏览器并访问输出的 `http://localhost:xxxx` 地址。

## 如何部署到 GitHub Pages
由于这是个标准的 Vite 项目：
1. 运行打包命令：
   ```bash
   npm run build
   ```
2. 将 `dist/` 目录推送到您的 GitHub 仓库的 `gh-pages` 分支，或在仓库设置中选择从 `main` 分支的某一个目录部署即可。
